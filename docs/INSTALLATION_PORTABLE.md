# Install on portable hosts

## 1. Prerequisites

Follow [package preparation](INSTALLATION.md). These adapters are compatibility guidance; native activation needs verification on the selected host version.

## 2. Install and discover

| Host | Route | Adapter |
| --- | --- | --- |
| Antigravity | Register the complete Antigravity archive through supported local plugin controls | [Guide](../adapters/antigravity/README.md) |
| GitHub Copilot | Register the complete Agent Plugins package on a supported surface | [Guide](../adapters/github-copilot/README.md) |
| VS Code | Install through the selected harness and inspect Agent Customizations diagnostics | [Guide](../adapters/vscode/README.md) |
| Generic Agent Skills | Point supported external discovery at the complete package skills directory | [Guide](../adapters/generic/README.md) |

## 3. Verify

Start a new session and run [shared verification](INSTALLATION.md). Confirm sibling framework resources resolve. Hosts that copy isolated skills need an adapter preserving these paths. Verify tools, hooks and delegation separately.

## 4. Update, rollback and remove

Keep prior archives. Change the registered package source, refresh and repeat verification. Restore the prior source to roll back. Remove registration/links to uninstall, preserving project data.

## 5. Troubleshoot

Missing skills indicate discovery/permission problems; missing framework files indicate broken package layout. Helpers need Python or a verified host equivalent. Record unresolved host compatibility explicitly.

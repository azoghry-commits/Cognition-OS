# Generic Agent Skills adapter

Hosts that implement the open Agent Skills convention can use the folders under `skills/` without adopting host-specific hooks or manifests. Install only the selected folders when the host has a small skill-description budget.

The scripts are optional. A host without Python can still follow the skill instructions and framework definitions, but deterministic calculations, DAG validation, project memory, and improvement ledgers must be reported as unavailable unless equivalent native tools are verified.

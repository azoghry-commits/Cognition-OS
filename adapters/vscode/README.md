# VS Code adapter

VS Code agent plugins can consume the canonical Agent Plugins 1.0 package. Enable agent plugin support for the selected harness, install the repository or runtime ZIP, then verify loaded skills in the Agent Customizations diagnostics view.

The active harness controls which custom agents, hooks, MCP servers, and delegation features are available. The portable baseline is the skill catalog plus local deterministic helpers. `analysis-plan` exposes dependency-safe waves for hierarchical, sequential, or parallel host execution.
